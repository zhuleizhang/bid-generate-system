代码注释全部使用中文编写，且只对重要业务逻辑进行注释。

**Why:** 用户希望代码注释让读者快速理解业务逻辑和决策原因，而非解释语法。简单的一眼就能看懂的代码不需要注释。

**How to apply:** 编写任何代码时，遵循以下规则：
- 注释用中文
- 只注释非显而易见的业务规则、边界条件、取舍原因、容易踩坑的地方
- 不注释简单的 getter/setter、CRUD、变量赋值、循环等基础语法
- 保持注释简洁，一行说清即可
